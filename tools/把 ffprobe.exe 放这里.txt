把 ffprobe.exe 放到这个目录
============================================================

为什么需要它
------------------------------------------------------------
本工具集的菜单 1 / 2 / 5，以及菜单 6 的视频合并 / 转码，需要
ffprobe 读取视频真实时长、码率、分辨率。工具本身不附带该程序
（完整包约 80~200 MB，且涉及 GPL 许可），需要你自行下载。

获取方式（任选其一）
------------------------------------------------------------
a) GitHub 构建（推荐，国内相对快）
   https://github.com/BtbN/FFmpeg-Builds/releases/latest
   在 Windows (x86_64) 下选 "GPL, static" 的 zip
   解压后进入 bin 目录，把 ffprobe.exe 复制到本文件夹
   （菜单 6 的视频合并 / 转码还需要 ffmpeg.exe，一并复制）

b) winget（会同时安装 ffmpeg）
   winget install Gyan.FFmpeg
   安装后 ffprobe 已在 PATH 中，本目录可以留空

c) gyan.dev（备用）
   https://www.gyan.dev/ffmpeg/builds/
   下载 "ffmpeg-release-essentials.zip"，取其中的 bin\ffprobe.exe

放好之后做什么
------------------------------------------------------------
双击上一层的 install.bat
它会检测到本目录内的 ffprobe.exe，并自动把 tools 目录加入
用户 PATH，之后在任意文件夹输入 tt 即可使用。

注意
------------------------------------------------------------
· 如果下载的是 "shared" 版本，ffprobe.exe 只有几百 KB，
  必须连同 avcodec-*.dll / avformat-*.dll / avutil-*.dll /
  swresample-*.dll 一起放到本目录，否则无法运行。
· 这里的 exe / dll 不会进入 Git 仓库（已在 .gitignore 中排除），
  仅存在于你本地。

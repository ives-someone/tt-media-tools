把 ffprobe.exe 放到这个目录
============================================================

为什么需要它
------------------------------------------------------------
本工具集的菜单 1 / 2 / 5 需要 ffprobe 读取视频真实时长、码率、
分辨率。工具本身不附带该程序（体积约 80~120 MB，且涉及 GPL
许可），需要你自行下载。

获取方式（任选其一）
------------------------------------------------------------
a) 单文件版（推荐，解压即用）
   https://www.gyan.dev/ffmpeg/builds/
   下载 "ffmpeg-release-essentials.zip"
   解压后进入 bin 目录，把 ffprobe.exe 复制到本文件夹

b) winget（会同时安装 ffmpeg）
   winget install Gyan.FFmpeg
   安装后 ffprobe 已在 PATH 中，本目录可以留空

放好之后做什么
------------------------------------------------------------
双击上一层的 install.bat
它会检测到本目录内的 ffprobe.exe，并自动把 tools 目录加入
用户 PATH，之后在任意文件夹输入 tt 即可使用。

注意
------------------------------------------------------------
· 如果下载的是 "shared" 版本，ffprobe.exe 只有几百 KB，
  必须连同 avcodec-*.dll / avformat-*.dll / avutil-*.dll /
  swresample-*.dll 一起放到本目录，否则无法运行。
· 这里的 exe / dll 不会进入 Git 仓库（已在 .gitignore 中排除），
  仅存在于你本地。

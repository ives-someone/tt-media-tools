## 二、下一阶段优先做

### 1. 抽 `modules\common.ps1`（技术债）

目的：减少 `Test-ArtBaseName`、`Get-DisplayWidth`、`PadTo`、`Format-TruncatedName`、`Show-MenuTitle` 在多模块重复。

- `ui.ps1` 保持“显示 / 交互”：配色、菜单、清屏、分隔线、表格格式化、`Show-MenuTitle`
- `common.ps1` 放“业务公共逻辑”：`Test-ArtBaseName`、附属文件白名单、`$videoExts`、UNC/长路径归一化、`.bak` 备份/删除/还原
- 原则：common 不依赖 ui，两者只定义函数/常量，无副作用
- `modules\ui\` 子文件夹暂时保留，不移动 `ui.ps1`，避免改所有 dot-source 路径

注意：抽取会动 `time_add` / `time_clear` / `nfo_sync_clean` 三处白名单逻辑，必须逐项回归。

### 2. `top_finder` 增加“重复候选清单”

目标：找出同一视频源被二次/多次重编码的候选，不替代哈希查重。

- 分组键：`round(时长)` + 分辨率（宽×高）
- 组内条件：时长差 ≤1 秒、分辨率相同
- 输出：组内 ≥2 个的候选组，列出路径、大小、码率、时长
- 不做哈希判定，只给候选供人工确认
- 可选导出 TXT/CSV；复用已加载的元数据，不重复扫盘
- 入口：结果页增加 `[d] 查找重复候选`

### 3. 版本检查

- `tt.ps1` 启动时可选检查 GitHub Releases 最新 tag
- 超时 2–3 秒，失败静默，不阻塞启动
- 有新版时在标题下提示；支持配置关闭
- 注意代理环境，检查失败按无更新处理

### 4. 空文件夹清理（小工具集合）

- 放入 `[0] 其他小工具集合`
- 范围：当前目录 / 递归子目录
- 先预览列表，默认跳过，确认后删除
- 不删根目录、不删含隐藏文件的目录
- 可选生成清单 TXT 便于回溯

## 三、明确暂不做 / 不做

- **默认日志**：隐私考虑，不落盘；需要时临时加 `-Debug` 开关，退出即删
- **视频工具硬核扩展**：HDR→SDR、10-bit、AV1、字幕/多音轨、切段、队列续跑——定位是“快速够用”，不做
- **视频预设**：保持手动调参，面向会调 ffmpeg 参数、只是懒得重复命令的人
- **NFO 刮削/整理/校验**：只处理 Emby 自动生成 nfo 的同步与孤立配套文件，不做刮削、评分、演员、封面
- **哈希查重**：用 Duplicate Cleaner，不重复造轮子
- **time_add / time_clear 时区**：无实际意义，不做
- **分发自动化**：GitHub Actions 打包、自动更新分发，暂不做
- **小工具扩展**：除空文件夹清理外，暂不加新工具

## 四、约定

- UI：所有显示行行首两格缩进；标题 `col_a_title`、分隔线 60 个 `=`；菜单不设“退出”项；`q/Esc` 语义见 `UI规范.md`
- 编码：`.ps1` 使用 UTF-8 **带 BOM** + CRLF；`.md` / `.txt` 使用 UTF-8 无 BOM + CRLF
- 交互：`Arrow-Menu` 竖向、`Select-Horizontal` 横向；数字 / 字母直达；底部提示统一 `[q/Esc]`
- 安全：删除类默认跳过、删除前 `.bak`、能撤销就提供撤销
- 测试：改动后至少做语法检查 + 代表性小样本测试；涉及 ffmpeg 的功能用短视频样本验证输出时长/分辨率

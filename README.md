> 一套基于 PowerShell 5.1 编写的 Windows 视频素材批量整理脚本工具集。
> 项目为个人自用产物，由作者结合实际使用需求，借助 AI 辅助迭代打磨完成，作者本身并非专业开发人员（啊对，我不会写代码，只能看懂简单的一点点代码逻辑，写这个全靠豆包磨）。
> 核心定位：对命名混乱的海量本地 / NAS 视频素材做**文件名标准化梳理**，方便后续人工分类、甄别疑似重复视频；**并非自动去重工具**，更非视频信息刮削工具。重点在于通过提取视频真实时长并写入文件名，便于排序检索，辅助人工比对：时长接近的文件，进一步判断是否为内容同源、码率 / 版本不同的素材。NFO、媒体配图相关能力属于附加顺手实现的周边功能，并非项目核心目标。除此以外，还另外附带了一些简单好用的重命名小工具。

## 📖 项目背景与用途

日常会积累大量命名杂乱的视频素材，同一内容经常留存多份副本，文件大小、编码码率各不相同，视频时长是一个很关键的比对线索。**个人没有找到能满足自己需求的成熟产品，于是手搓了这套脚本工具集。**

工具集主要完成这些事情：

1. 读取视频元数据（真实时长、码率、分辨率），将时长信息嵌入文件名，借助文件管理器排序、搜索，方便人工筛选时长相近的文件，辅助甄别是否为同源不同版本素材；
2. 对已经携带时间标记的文件名做清理，自动处理重命名冲突；
3. 批量扫描目录，按文件大小、码率、长边分辨率、视频时长生成导出清单，用于筛选大体积、高码率的素材；
4. 附带若干素材整理辅助小工具；
5. 所有会修改磁盘文件的操作均提供预览，支持导出新旧映射备份，部分场景支持会话内撤销，降低误操作风险。

> 
> 重要提醒：**本工具不会自动识别、自动删除重复视频**，仅将时长信息暴露在文件名，素材是否重复交由使用者人工判断。NFO、配图跟随重命名属于附加适配功能。

## ✨ 已实现功能特性

1. ffprobe 并发调用处理，大批量视频元数据读取；Ctrl+C 中断时可清理已拉起的 ffprobe 子进程，避免遗留僵尸进程。
2. 修改文件前提供预览；支持 `s` 预演模式，仅导出新旧映射备份文本，不改动磁盘上任何文件；部分改名操作在**当前脚本会话内**支持 `u` 撤销。
3. 支持 UNC 网络 NAS 路径；扫描时统计访问拒绝目录、元数据读取失败条目；重命名环节自动处理文件重名冲突。
4. 控制台单按键交互，无需回车，整套工具交互流程统一。
5. maxm 扫描脚本支持读取目录下`blacklist.txt`黑名单，跳过指定名称文件夹不参与扫描。

## ⚠️ 已知局限与注意事项

> 
> 本项目为个人自用、AI 辅助完成的工具，并非专业工业级软件，使用前请知悉：

1. 平台约束：仅面向 Windows PowerShell 5.1，不支持 Linux /macOS。
2. 外部依赖：需要使用者自行准备 `ffprobe.exe`，工具本身不携带、不会自动下载该程序。
3. 代码现状：各子脚本存在一定重复代码，未抽离公共模块库；主要设计为交互式控制台运行，参数化调用能力弱，不太适合直接嵌入自动化流水线。
4. 撤销能力边界：改名撤销仅在本次脚本运行会话内有效；关闭程序窗口之后，无法内存撤销，只能依靠预演导出的备份 txt 做手动恢复。
5. NFO 改写限制：NFO 内部 XML 文本修改只能撤销文件名，文本内容本身无法回滚，脚本会输出相关警告，使用前建议做好对应文件备份。
6. 黑名单能力仅在 `maxm.ps1` 扫描工具实现，改名类脚本不支持黑名单配置。
7. 虽然对部分特殊字符路径做了兼容，但面对畸形文件名、emoji 文件名，仍然存在小概率异常风险；处理重要素材建议先行备份副本。
8. 无自动去重逻辑，全部重复视频的甄别、处置工作由使用者人工完成。

## 🚀 使用方式

1. 将全部脚本文件解压至同一个目录，推荐放置在分区根目录，例如 `C:/ps`、`C:/bat`；
2. **把该目录添加到系统环境变量 PATH**：此电脑 → 属性 → 高级系统设置 → 高级 → 环境变量 → 在系统变量的 `Path` 中新增上面这个文件夹路径；
3. 进入**需要处理视频的目标文件夹**，在文件夹空白处按住 `Shift` + 鼠标右键，选择「在此处打开 PowerShell 窗口」。

> 
> ⚠️ 不建议直接右键打开终端，终端在 SMB 网络共享 (UNC) 路径下会出现路径异常，打开后命令行不位于原路径；Shift + 右键唤起原生 PowerShell 窗口兼容性更好。

4. 确认 PowerShell 当前工作路径就是待处理素材的文件夹。
   - 如果已经配置好 PATH 环境变量：直接输入 `tt` 回车即可启动工具集主菜单；
   - 如果没有配置 PATH，则需要输入完整路径，示例：`C:/ps/tt.bat` 或者 `C:/ps/tt.ps1`；
5. 进入工具后，凡是会修改磁盘文件的功能，先按预览核对，确认逻辑符合预期，再执行真实改名操作，改名后还有一次u撤销的机会，错过则不可撤销。

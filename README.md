# TT_Media_Tools

> 一套基于 PowerShell 编写的 Windows 视频素材批量整理脚本工具集。

> 项目为个人自用产物，由作者结合实际使用需求、借助 AI 辅助迭代打磨完成。作者本身并非专业开发人员（啊对，我不会写代码，只能看懂简单的一点点逻辑，写这个全靠 AI 磨）。

> **核心定位**：对命名混乱的海量本地 / NAS 视频素材做**文件名标准化梳理**，方便后续人工分类、甄别疑似重复视频。
> **不是**自动去重工具，也**不是**视频信息刮削工具。重点在于把视频真实时长写进文件名，便于排序检索、辅助人工比对——时长接近的文件，再进一步判断是否为内容同源、码率 / 版本不同的素材。
>
> NFO 资产盘点、媒体配图跟随属于顺手实现的周边能力。其中「递归扫描 NFO 导出 CSV」（`nfo_export`，读现有元数据，很快）与「TOP XX 查找排序」（`top_finder`，用 ffprobe 读真实文件，很准）构成互补的分析双引擎。

## 📖 主界面

```
============================================================
  TT_Media_Tools 视频重命名工具集
============================================================

  处理目录：D:\素材\某文件夹

  [1] 视频提取时长并重命名添加
  [2] 识别文件名内视频时长文字并按多种需求清理
  [3] Emby nfo同步与孤立文件清理
  [4] 递归扫描 NFO，提取信息导出 CSV，便于筛查排序
  [5] TOP XX 的视频/文件查找和输出（双模式）
  [6] 视频合并 / 转码工具（支持无损快速合并）
  [0] 其他小工具集合

  [↑↓]移动  [0-6]直达  [Enter]确认  [q/Esc]退出
```

`[0]` 进入二级菜单（跑完一个小工具自动回主菜单）：

| 子菜单 | 脚本 | 功能 |
|---|---|---|
| 1 | `modules\ext_lower.ps1` | 文件扩展名规整，把 `.MP4` 等大写扩展名批量转小写 |
| 2 | `modules\cn_to_arabic.ps1` | 文件名 / 文件夹名里的汉字数字转阿拉伯数字 |
| 3 | `modules\lnk_replace.ps1` | 快捷方式 lnk 目标路径批量替换 |

除主菜单外，所有子菜单统一支持：`←→` 或 `↑↓` 移动、字母 / 数字直达、`Enter` 确认、`q` / `Esc` 退出。

## ⚙️ 环境依赖

| 项目 | 要求 |
|---|---|
| 操作系统 | Windows 10 / 11 |
| PowerShell | **5.1**（系统自带）或 **7.x**，两者均已实测通过 |
| ffprobe.exe | 需自行准备，**推荐放进 `tools\` 目录**（见下） |
| ffmpeg.exe | 菜单 6（视频合并 / 转码）需要，通常与 ffprobe 同目录发布 |

- `tt.bat` 会**优先用 PowerShell 7** 启动，找不到 `pwsh` 时自动回退到系统自带的 PowerShell 5.1。
- 不建议直接右键打开终端：SMB 网络共享（UNC 路径）下原生右键可能定位不到目标目录，用 `Shift` + 右键「在此处打开 PowerShell 窗口」更稳。

### 关于 ffprobe / ffmpeg

菜单 1 / 2 / 5 需要 `ffprobe.exe` 读取视频真实时长、码率、分辨率；菜单 6 的视频合并 / 转码同时还要 `ffmpeg.exe`（ffprobe 读参数、ffmpeg 负责拼接与转码）。

**本工具集不附带该程序**：完整包约 80~200 MB（视构建而定），且属于 GPL 许可，不适合随脚本分发。

**获取**（任选其一）：

- **GitHub 构建（国内相对快）**：<https://github.com/BtbN/FFmpeg-Builds/releases/latest>
  在 `Windows (x86_64)` 下选 **GPL, static** 的 zip（文件名形如 `ffmpeg-n9.0-latest-win64-gpl-9.0.zip`），解压后取 `bin\ffmpeg.exe` 与 `bin\ffprobe.exe`
- 备用站点：<https://www.gyan.dev/ffmpeg/builds/> → `ffmpeg-release-essentials.zip` → 取其中的 `bin\ffprobe.exe`
- 或用 winget：`winget install Gyan.FFmpeg`

**放置**（推荐方式）：

1. 把 `ffprobe.exe`（菜单 6 还需要 `ffmpeg.exe`）放进本工具集的 `tools\` 目录
2. 双击 `install.bat`
3. 脚本会自动把 `tools\` 加入用户 PATH

> **从 GitHub 下载 zip 后请先运行 `install.bat`**：解压出来的脚本带有“网络下载”标记，`install.bat` 会先解除 `install.ps1` 的锁定，`install.ps1` 再批量解除整个目录的脚本锁定。
> 如果直接输入 `tt` 提示“未进行数字签名”，说明还没解锁：运行一次 `install.bat`，或运行 `tt.bat`（首次会自动解锁 `tt.ps1` 和 `modules\` 下的脚本）。

> 也可以自己把它放进系统 PATH，`install.bat` 检测到就直接使用，不需要 tools 目录。
> 如果下载的是 shared 版本（`ffprobe.exe` 只有几百 KB），必须连同 `avcodec-*.dll` 等一起放入 `tools\`，否则无法运行。

## 📖 项目背景与用途

日常会积累大量命名杂乱的视频素材，同一内容经常留存多份副本，文件大小、编码码率各不相同，而**视频时长**是一个很关键的比对线索。

个人没找到能满足需求的成熟产品，于是手搓了这套脚本。主要做这些事：

1. 读取视频元数据（真实时长、码率、分辨率），把时长写进文件名，借助文件管理器排序、搜索，方便人工筛选时长相近的文件；
2. 对已经带时间标记的文件名做清理，自动处理重命名冲突；
3. 批量扫描目录，按文件大小 / 码率 / 长边分辨率 / 视频时长生成清单，用于筛查大体积、高码率素材；
4. 扫描 Emby / Jellyfin 生成的 NFO，提取流信息导出 CSV，用于资产盘点与孤立 NFO 排查；
5. 附带若干整理小工具；
6. 所有会修改磁盘文件的操作都提供**预览**，多数支持**撤销**，降低误操作风险。

> ⚠️ **重要提醒**：本工具**不会自动识别、自动删除重复视频**。它只是把时长信息暴露在文件名上，素材是否重复由使用者人工判断。

## 🧩 功能模块

| 菜单 | 脚本 | 功能 |
|---|---|---|
| 1 | `modules\time_add.ps1` | **添加时长**。三种模式：开头 / 结尾 / 仅时长（不保留原名）。可选 Emby 配图与 NFO 标签跟随改名 |
| 2 | `modules\time_clear.ps1` | **清理时长文字**。两种模式：只保留时间（新名含时间，位置可选开头/结尾/任意）、删除时间片断（保留其余文本） |
| 3 | `modules\nfo_sync_clean.ps1` | **Emby nfo 同步与孤立文件清理**。同步同名 nfo 的 `<title>` / `<sorttitle>`；清理无同名视频的 nfo / 图片，默认跳过、删除前 `.bak`、可撤销 |
| 4 | `modules\nfo_export.ps1` | **NFO 资产盘点**。递归扫描 NFO，提取时长 / 编码 / 分辨率 / 码率等导出 CSV，供 Excel 筛选排序 |
| 5 | `modules\top_finder.ps1` | **TOP XX 查找排序**。按大小 / 码率 / 分辨率 / 时长排序，支持多层漏斗筛选、二次排序、导出 TXT；另有 AI 驱动的非交互模式。命令行短名 `maxm.ps1` 保留为等价入口 |
| 6 | `modules\video_tool.ps1` | **视频合并 / 转码**。合并：当前目录多段首尾拼接，参数一致 `-c copy` 无损秒合，不一致改有损（H.265/H.264，QSV ICQ/CBR 或 CPU CRF）并统一分辨率 / 帧率。转码：逐个文件按同一套预设重编码，保持原分辨率，帧率可保持或自定义 |
| 0-1 | `modules\ext_lower.ps1` | **扩展名规整**。把 `.MP4` / `Png` 等大写扩展名批量转小写，可选递归 |
| 0-2 | `modules\cn_to_arabic.ps1` | **汉字数字转换**。把文件名里的「一、二 …… 十」转成「01、02 ……10」，支持十一 / 二十三 等组合 |
| 0-3 | `modules\lnk_replace.ps1` | **快捷方式批量替换**。批量修改 `.lnk` 的目标路径 / 起始位置 / 参数，适配 NAS 迁移、盘符变更；支持预览、撤销、目标存在性检查 |

**公共模块**（不由菜单直接调用）：

| 文件 | 作用 |
|---|---|
| `modules\ui\ui.ps1` | 公共 UI 框架：配色体系、横向 / 竖向菜单、清屏、分隔线 |
| `modules\ui\ui_colors.ps1` | 配色预览工具（调试用），运行后直观展示所有配色函数的实际效果，类似调色盘 |
| `modules\maxm.ps1` | `top_finder.ps1` 的兼容入口（3 行转发器），供命令行短名调用与 AI 模板使用 |

## ✨ 已实现特性

1. **ffprobe 并发调用**处理大批量元数据；并发额度只统计本脚本自己启动的进程，不会因为你同时开着转码软件而卡死。
2. **Ctrl+C 可清理**已拉起的 ffprobe 子进程，不留僵尸进程。
3. **预览优先**：改名前先出预览表；部分功能支持只导出映射文本、不动磁盘。
4. **撤销**：改名、NFO 改写、孤立文件清理均支持撤销；NFO 用字节级 `.bak` 备份，撤销后编码不变。
5. **重名冲突自动处理**：执行前检测目标名是否已被占用，冲突项标出来并跳过，不会中途报错留下半改状态。
6. **NFO 写入安全**：编码探测（UTF-8 / GBK / UTF-16）后按原编码回写；标题做 XML 转义；只改已存在的标签，不破坏原有结构。
7. **支持 UNC 网络路径**，兼容含 `[ ]`、中文、空格的目录名。
8. **交互统一**：全部子模块使用同一套箭头菜单，支持方向键、字母／数字直达、`q` / `Esc`。
9. **top_finder 双模式**：既能交互操作，也能用命令行参数由 AI 生成命令直接执行；支持读取 `nfo_export` 的 CSV 作为快速数据源。
10. **top_finder 全量导出**：`-DumpAll` 可导出本次扫描到的全部视频数据集（CSV），便于自行分析。
11. **视频合并**：默认无损拷流；参数不一致时用 concat 滤镜重编码，自动统一分辨率 / 帧率、补齐缺音轨片段；QSV 硬件编码先做真实试编码再启用；合并后复核输出时长，失败自动清理残缺文件并提示改走有损。
12. **视频合并兼容 SMB**：UNC 路径会自动尝试 `\\?\UNC\` 与映射盘形式，失败时重试一次；探测改用独立进程重定向读取 ffprobe 输出，规避 UNC 下 PowerShell 丢输出导致的误判；失败时把 ffprobe 报错直接显示在「读取失败」清单里。
13. **视频转码**：逐个文件重编码，保持原分辨率，帧率默认保持原样或手动指定；复用合并的编码器 / 质量参数体系（QSV 优先）；音频为 AAC 时直接复制、其余转 AAC；输出可选 `转码成果` 子文件夹（保留原名）或源文件夹（原名加 `_转码`）；失败自动清理残缺文件。
14. **处理范围**：扫描后可选「全部」或「指定序号」（如 `1-3,5`）。合并严格按输入顺序拼接并在执行前列出确认；转码共用同一选择。
15. **转码体验**：按 `p` 暂停 / 继续；短边 ≤1500（含 2K 1440p）的文件双槽滚动补位（完成一个立即补下一个），仅 4K 独占运行；并发时显示每个任务的百分比与倍速；编码菜单默认「一键按上次」，沿用上次参数与输出位置，跳过确认直接开始；帧率可保持原样或自定义 1~120 fps。
16. **环境**：QSV 检测结果缓存 7 天（ffmpeg 路径 / 版本变化时自动重测）；从 GitHub 下载 zip 后，`install.bat` 或 `tt.bat` 会自动解除脚本的网络下载锁定。

## ⚠️ 已知局限与注意事项

> 本项目为个人自用、AI 辅助完成，并非专业工业级软件，使用前请知悉：

1. **仅面向 Windows**，不支持 Linux / macOS。
2. **需要自行准备 `ffprobe.exe`；菜单 6 还需要 `ffmpeg.exe`**，工具不携带、不自动下载。
3. **撤销仅在本次运行会话内有效**。关闭窗口后无法内存撤销；NFO 有 `.bak` 备份可手动还原，文件名只能依靠预先导出的映射文本。
4. **黑名单仅 `top_finder.ps1` 支持**，改名类脚本不支持。
5. **`top_finder.ps1` 的 CSV 数据源仅交互模式可用**，非交互模式只做真实文件扫描。
6. **`lnk_replace.ps1` 不认乱码路径**：目标路径含 `?`（emoji 无法识别）的快捷方式会被直接跳过，需要借助第三方工具（如 LiNK Fixer）处理。
7. **没有自动去重逻辑**，重复视频的甄别与处置全部由人工完成。
8. **极端窗口尺寸下菜单显示会异常**：窗口高度不足以容纳整个菜单时，重绘可能出现重复行。正常尺寸不受影响。
9. **畸形文件名、emoji 文件名**仍存在小概率异常风险；处理重要素材建议先备份副本。
10. **视频合并只处理当前文件夹**，不递归子文件夹；输出命名为 `合并_<N>段合并 <各段原名> <合并时长>`（各段原名里的 `XXhXXmXXs` / `XXmXXs` 会先去掉，清理后为空的段用「第N段」占位；名称超长时截断末尾但保留时长标签），不会覆盖原文件。转码默认输出到 `转码成果\` 子文件夹并保留原名，也可选源文件夹（原名后加 `_转码`，排序时与原片相邻）。合并的拼接顺序由「处理范围」里输入的序号决定，不再是固定自然排序。
11. **合并与转码的重编码固定输出 8-bit**（CPU 用 yuv420p，QSV 用 nv12）：10-bit / HDR 素材会被压到 8-bit SDR。
12. **视频合并在 SMB 路径下仍读不到文件时**，界面会给出 ffprobe 的具体报错；可先把共享映射为盘符，从映射盘进入后再运行。
13. **以 `合并_` 开头或 `_转码` 结尾的文件会被当成历史产物跳过**，不会参与扫描；若它们其实是你的素材，请先改名。

> ⚠️ 处理重要素材前，**请务必先备份一份副本**，规避不可预期异常带来的数据风险。

## 🚀 使用方式

1. 把整个目录解压到任意位置，推荐放在分区根目录（例如 `C:\ps`）。
2. 双击 `install.bat`，选择「安装」把该目录加入系统 `PATH`。
   如果是 GitHub 下载的 zip，`install.bat` 会同时解除脚本的网络下载锁定，避免 `RemoteSigned` 下报“未进行数字签名”。
   （也可以手动配置：此电脑 → 属性 → 高级系统设置 → 环境变量 → 系统变量 `Path` 中新增该目录）
3. 进入**需要处理的视频文件夹**，在空白处按住 `Shift` + 鼠标右键，选择「在此处打开 PowerShell 窗口」。
4. 确认当前路径就是目标文件夹，输入 `tt` 回车即可启动主菜单。
   - 未配置 PATH 时，也可以直接运行完整路径的 `tt.bat`。
5. 凡是会修改文件的功能，**先看预览**，确认符合预期再执行；执行后仍有一次撤销机会。
